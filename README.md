# 卡拍拍卡牌查詢（書籤小工具）

在 trade.kapaipai.tw 上按一下書籤，跳出查詢面板：
- 輸入**卡號**：只列出編號完全符合的卡，繁中、日文、英文分三欄顯示
- 輸入**卡名**：模糊比對，以表格列出，可排序、篩選語言

> 目前僅支援「寶可夢卡牌（PTCG）」查詢，其他卡牌遊戲的查詢後續再開發。

## 安裝
1. 用瀏覽器開啟 `dist/install.html`
2. 把「卡牌查詢」連結拖曳到書籤列（拖曳不行就新增書籤，網址貼 `dist/bookmarklet.txt` 的內容）

## 使用
- 開啟 trade.kapaipai.tw 任一頁 → 按書籤 → 輸入卡號或卡名 → Enter
- 輸入內容會自動判斷是卡號還是卡名，不用切換
- 再按一次書籤隱藏／顯示，`Esc` 關閉；會記住上次查詢的內容

### 卡號
- 支援格式：`s10a 073`、`S10a-073`、`S-P 201`、`S-P-201`（大小寫、前導零都不影響）
- 英文版的擴充包代號和繁中／日文不同（例如 `MEW 165`、`PAF 232`），同一張卡要用英文代號另外查
- 每筆顯示：卡圖、卡名、稀有度、最低價、均價；點卡片在新分頁開啟該卡頁面
- 看起來像卡號但沒有編號符合的卡時（例如 `Mewtwo 2`），會自動改用名稱搜尋

### 卡名
- 模糊比對：名稱包含輸入文字的卡都會列出（例如 `超夢ex` 也會列出「火箭隊的超夢ex」、起始牌組）
- 表格欄位：語言、卡名、卡號／擴充包、稀有度、最低價、均價；點欄位標題排序（預設最低價由低到高，沒有商品的排最後）
- 可勾選要顯示的語言，或勾「只顯示名稱完全相同」
- 中文名可以查到繁中＋日文卡（日文卡有中文名），查不到英文卡；英文卡請用英文名（例如 `Mewtwo ex`）
- 網站一次最多回傳 500 張卡，熱門名稱（例如 `皮卡丘`）會被截斷，面板會提示改用更完整的名稱或卡號

## 運作方式
- 呼叫卡拍拍自己的 API：`GET /api/card/getFilteredList?game=&name=<卡號或卡名>`（`game` 留空＝所有遊戲一起回傳，再挑出 `pkmtw` 繁中、`pkmjp` 日文、`pkmen` 英文）
- 卡號模式：從每張卡的 `rareList` 過濾 `packId` + `packCardId` 符合輸入的項目
  - `packCardId` 有兩種格式：`073`、`S10a-073`，比對前會去掉擴充包前綴與前導零
- 卡名模式：直接使用 API 的模糊搜尋結果（API 會比對卡號、中文名、日文名）
- 卡片頁連結：`/cardredirect/<game>?cardkey=&rare=&pack=&packcard=`
- 卡圖：`https://static.kapaipai.tw/image/card/<game>/<cardGlobalKey>/<packId>/<packCardId>/<rare>.jpg`

## 為什麼不是獨立網頁
- API 沒有開放 CORS，其他網域的網頁無法呼叫
- 從本機用 Node / curl 直接連會被 TLS 拒絕（alert 49 access denied），本機代理伺服器也行不通
- 書籤在卡拍拍頁面內執行，屬於同網域請求，沒有上述限制

## 修改
- 原始碼：`src/kapaipai-lookup.js`（只能用 `/* */` 註解，build 時會移除）
- 改完執行 `node build.mjs`，重新產生 `dist/`，書籤要重新安裝
- 卡拍拍改版導致 API 或欄位名稱變動時，這個工具就會失效
